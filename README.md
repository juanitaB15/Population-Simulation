# Population-Simulation
# This is one of my first Freshman year projects I made using python in PyGame. 
# This Population Simulation features a simulation of an ecosystem with sheep that eat the grass, wolves that eat the sheep, and ahunter that hunts the wolves. with a Start and Stop button to star and stop the simulation and includes a side bar that gives information and updates the number of frames elapsed, number of alive sheep, number of dead sheep, number of alive wolves, number of dead wolves, the regrowth rate of the grass, and frames per second. On the main screen is a bunch of grass with sheep that are multicolored circles that stay in one position for a few seconds and eat the grass (5 times) in that position until it gets beige (barren). The grass regrows after 10 frames. The sheep, they then move one cell to left, right, up, or down without going off the board. The wolves (black circles) then move one cell to left, right, up or down without going off the board in search of these sheep. When they find a sheep, they eat the sheep and gain energy. The sheep die when a wolf eats them and a wolf dies if it runs out of energy or if a hunter kills it (lands on the same cell as it). The hunter is purple circle and moves one cell to left, right, up, or down without going off the board while searching for a wolf to kill.
