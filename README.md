# Population-Simulation
# This freshman-year project, developed in Python using the PyGame library, is designed and coded based on an ecological simulation to model predator-prey dynamics and resource management.
# The simulation models three interacting populations: sheep (herbivores), wolves (predators), and a hunter (apex predator). I also included specific colors to define Grass, Sheep, Wolves, and the Hunter with grid-based movement to move species one cell at a time and boundaries to prevent them from moving off the board. To manage resources like Grass, I included 5 states of the grass (lush to barren) and a regrowth cycle of 10 frames to limit the sheep's consumption.
# I also programmed the sheep's behavior that includes stationary grazing (5 frames to consume grass) and movement until they die upon wolf predation, the wolves' behavior that includes a search algorithm for prey as they gain energy by eating sheep and die from energy depletion or hunter predation, and the hunter's behavior that includes a search pattern targeting wolves.
# To analyze the ecosystem, I created a side panel that implements Start and Stop functionality using event handling, updates on framed elapsed, frames per second, grass regrowth rate, and the live/dead counts for both sheep and wolves.
